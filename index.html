SHAP-Coded Insights: Interpretable Structural Similarity of Programs with GraphCodeBERT
Amal S  ·  Niranjan A.R  ·  M.G. Thushara  ·  Amrita Vishwa Vidyapeetham, Amritapuri
  • Multi-component code similarity pipeline combining GraphCodeBERT semantic embeddings, AST structural comparison (pycparser, javalang), and token overlap for C and Java; scored 0.77–1.00 on real student–instructor submission pairs.
  • SHAP attribution via surrogate Random Forest attributes per-feature importance scores, producing student-facing feedback with unified diff visualization.

EduRAG — Explainable RAG for Educational Q&A
● Final Year Research Project · Paper under review

End-to-end explainable RAG system with hybrid retrieval (BM25 + FAISS + RRF), HyDE query expansion, MS-MARCO cross-encoder reranking, and a multi-level attribution framework. Integrated LLaVA-Phi3 for diagram captioning and DeepSeek R1 (8B) via Ollama for local, privacy-first inference. The system includes an explainability layer for cross-encoder evidence attribution and source consensus detection.
